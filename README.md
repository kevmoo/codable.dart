# package:codable

Next-generation high-performance zero-allocation serialization framework for Dart.

## Overview

* **Layer 1**: Direct UTF-8 byte stream and buffer parsing atoms (`dart:convert`).
* **Layer 2**: Standard format-agnostic ecosystem contracts (`package:codable`).
* **Layer 3**: Zero-boilerplate code generation and Dart 4 class augmentations (`package:codable_builder`).
