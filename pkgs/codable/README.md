High-performance, zero-intermediate-tree serialization contracts and JSON
streaming drivers for Dart.

`package:codable` maps between JSON payloads and strongly typed Dart classes
without allocating intermediate `Map<String, dynamic>` and `List<dynamic>`
object trees.

## 1. The General `Codable` Model

Traditional Dart JSON serialization (`jsonDecode` + `json_serializable`) runs in
two passes:

1. Parse UTF-8 bytes or a `String` into an untyped `Map<String, dynamic>` and
   `List<dynamic>` heap graph.
2. Traverse that map graph to allocate typed Dart model instances (and the
   reverse on encode).

`package:codable` replaces the intermediate map graph with structured **cursor
containers** (`Decoder` and `Encoder`) and **stateless `const` companion
classes** (`Codable<T>`, `Decodable<T>`, `Encodable<T>`). Domain model classes
stay completely free of serialization methods or interfaces; companion objects—
whether generated by `package:codable_builder` or written by hand—read and write
fields directly through `Decoder` and `Encoder` containers, decoupling domain
models from how the JSON payload is represented in memory.

### Library Imports

- `package:codable/codable.dart` — Format-agnostic companion contracts
  (`Codable<T>`, `Decodable<T>`, `Encodable<T>`, `SuperDecodable<T>`, `Decoder`,
  `Encoder`, `KeyOptions`, and `@Codable` annotations).
- `package:codable/codable_json.dart` — Re-exports `package:codable/codable.dart`
  plus the JSON drivers (`JsonCodableDecoder`, `JsonCodableEncoder`) and
  low-level UTF-8 token streaming primitives (`JsonTokenReader`,
  `JsonTokenWriter`, `JsonKeyOptions`, `jsonUtf8`).

### Core Companion Contracts

```dart
abstract interface class Decodable<T> {
  const factory Decodable.fromFunction(T Function(Decoder decoder) decode) =
      _FunctionDecodable<T>;

  T decode(Decoder decoder);
}

abstract interface class Encodable<T> {
  const factory Encodable.fromFunction(
    void Function(T value, Encoder encoder) encode,
  ) = _FunctionEncodable<T>;

  void encode(T value, Encoder encoder);
}

@Target({TargetKind.classType})
@optionalTypeArgs
abstract interface class Codable<T> implements Decodable<T>, Encodable<T> {
  const factory Codable({
    bool createEncoder,
    bool createDecoder,
    bool useGoldenMask,
    FieldRename fieldRename,
  }) = CodableAnnotation;

  const factory Codable.fromFunctions({
    required T Function(Decoder decoder) decode,
    required void Function(T value, Encoder encoder) encode,
  }) = _FunctionCodable<T>;
}
```

### Container Shapes (`Decoder` & `Encoder`)

A `Decoder` or `Encoder` represents a single value position in the payload and
opens one of four container shapes:

- **`KeyedDecoder` / `KeyedEncoder` (`decoder.keyed({options})` /
  `encoder.keyed({options})`)**:
  Sequential streaming over object key-value pairs (`{ "id": 1, "name": "Ada" }`).
  Callers advance through fields in wire order using `while (keyed.moveNextKey())`,
  match expected keys in `O(key length)` via `keyed.selectKeyIndex(options)` (without
  allocating a `String` per key), and call `keyed.skipValue()` on unknown fields.
- **`MappedDecoder` (`decoder.mapped()`)**:
  Random-access key lookup (`mapped.containsKey('id')`, `mapped.readInt('id')`,
  `mapped.decodeKey('user', const UserCodable())`). Used when fields must be
  inspected out of order or when backed by an in-memory object representation
  such as browser `JSON.parse()` on Web JS.
- **`UnkeyedDecoder` / `UnkeyedEncoder` (`decoder.unkeyed()` /
  `encoder.unkeyed()`)**:
  Sequential iteration over arrays (`[1, 2, 3]`) using `while (unkeyed.moveNext())`,
  plus bulk typed-list helpers (`decodeIntList()`, `decodeDoubleList()`,
  `decodeFloat64List()`, `decodeStringList()`).
- **`SingleValueDecoder` / `SingleValueEncoder` (`decoder.singleValue()` /
  `encoder.singleValue()`)**:
  Reads or writes a single scalar primitive (`int`, `double`, `String`, `bool`,
  `null`) or delegates a custom wrapper type.

### Target-Aware Execution (VM / Wasm vs. Web JS)

`package:codable/codable_json.dart` automatically selects the fastest backend
for the current compilation target:

- **Dart VM / AOT / Wasm (`driver_streaming.dart`)**: Streams directly over
  contiguous UTF-8 `Uint8List` buffers via `JsonTokenReader` and formats UTF-8
  bytes directly via `AdaptiveJsonTokenWriter`, matching keys against
  pre-hashed UTF-8 byte tables (`KeyOptions`) with zero intermediate `Map`
  allocations.
- **Web JS (`dart2js` / `ddc` via `driver_js.dart`)**: Delegates parsing to the
  browser's native C++ `JSON.parse()` and traverses `JSObject` / `JSArray`
  properties directly via `package:web` / `dart:js_interop` without wrapping
  objects in Dart `LinkedHashMap` instances.

## 2. Using `JsonCodableDecoder` and `JsonCodableEncoder`

### Defining an Annotated Model

Annotate your domain class with `@Codable()` and include a `part '<file>.g.dart';`
directive. `package:codable_builder` generates a `const` companion class
`<ClassName>Codable` implementing `Codable<<ClassName>>`—leaving your domain
class completely clean:

```dart
import 'package:codable/codable_json.dart';

part 'user.g.dart';

@Codable(fieldRename: FieldRename.snake)
class User {
  final int id;
  final String displayName;

  @CodableKey(name: 'role_level', aliases: ['roleLevel'], defaultValue: 1)
  final int roleLevel;

  @CodableKey(ignore: true)
  final String? localCacheTag;

  const User({
    required this.id,
    required this.displayName,
    this.roleLevel = 1,
    this.localCacheTag,
  });
}
```

### Decoding JSON (`JsonCodableDecoder`)

```dart
import 'dart:async';
import 'dart:typed_data';
import 'package:codable/codable_json.dart';

void decodeExamples(Uint8List utf8Bytes, String jsonString) {
  // 1. Decode directly from UTF-8 bytes (preferred fast path on VM/AOT/Wasm):
  final userFromBytes = const UserCodable().decode(
    JsonCodableDecoder.fromBytes(utf8Bytes),
  );

  // 2. Decode from a JSON String:
  final userFromString = const UserCodable().decode(
    JsonCodableDecoder.fromString(jsonString),
  );

  // 3. Decode a top-level JSON array of models:
  final users = const UserCodable().decodeList(
    JsonCodableDecoder.fromBytes(utf8Bytes),
  );
}
```

For streaming byte sources (`Stream<List<int>>`, such as `HttpClientResponse` or
`File.openRead()`), use `JsonCodableDecoder.startChunkedConversion`:

```dart
Future<User> decodeStream(Stream<List<int>> byteStream) {
  final completer = Completer<User>();
  final outSink = ChunkedConversionSink<User>.withCallback((decoded) {
    completer.complete(decoded.single);
  });
  final byteSink = JsonCodableDecoder.startChunkedConversion(
    outSink,
    const UserCodable(),
  );
  byteStream.listen(
    byteSink.add,
    onError: completer.completeError,
    onDone: byteSink.close,
    cancelOnError: true,
  );
  return completer.future;
}
```

### Encoding JSON (`JsonCodableEncoder`)

```dart
import 'dart:typed_data';
import 'package:codable/codable_json.dart';

void encodeExamples(User user) {
  // 1. Encode directly to a UTF-8 Uint8List:
  final Uint8List utf8Bytes = JsonCodableEncoder.toBytes(
    user,
    const UserCodable(),
  );

  // 2. Encode to a JSON String:
  final String jsonText = JsonCodableEncoder.encode(
    user,
    const UserCodable(),
  );

  // 3. Append UTF-8 bytes into an existing BytesBuilder sink:
  final builder = BytesBuilder(copy: false);
  JsonCodableEncoder.toSink(builder, user, const UserCodable());

  // 4. Encode a top-level list of models:
  final listBytes = JsonCodableEncoder.toBytes(
    [user],
    const UserCodable().list,
  );
}
```

### Passing Runtime Context (`userInfo`)

Both `JsonCodableDecoder` and `JsonCodableEncoder` accept an optional `userInfo`
map (`Map<Object, Object?>`) that propagates to all nested containers and custom
companions:

```dart
final user = const UserCodable().decode(
  JsonCodableDecoder.fromBytes(
    utf8Bytes,
    userInfo: const {'allowLegacyIds': true},
  ),
);
```

## 3. Implementing Your Own `Codable`

You can implement `Codable<T>`, `Decodable<T>`, or `Encodable<T>` directly—with
zero code generation—for hand-written models, custom scalar types, third-party
types you don't own, or polymorphic hierarchies.

### A. Manual `Codable<T>` Companion Implementation

Pre-compile your expected field names once into a `static final KeyOptions`
table and iterate with `keyed.moveNextKey()` and `keyed.selectKeyIndex`:

```dart
import 'package:codable/codable.dart';

class Point {
  final double x;
  final double y;
  final String? label;

  const Point({required this.x, required this.y, this.label});
}

final class PointCodable implements Codable<Point> {
  const PointCodable();

  static final KeyOptions _options = KeyOptions.of(['x', 'y', 'label']);

  @override
  Point decode(Decoder decoder) {
    final keyed = decoder.keyed(options: _options);
    double? x;
    double? y;
    String? label;

    while (keyed.moveNextKey()) {
      switch (keyed.selectKeyIndex(_options)) {
        case 0:
          x = keyed.readDouble();
        case 1:
          y = keyed.readDouble();
        case 2:
          label = keyed.readNullableString();
        default:
          keyed.skipValue();
      }
    }

    if (x == null || y == null) {
      throw const CodableException('Point requires both "x" and "y" fields.');
    }
    return Point(x: x, y: y, label: label);
  }

  @override
  void encode(Point value, Encoder encoder) {
    final keyed = encoder.keyed(options: _options);
    keyed.encodeDouble('x', value.x);
    keyed.encodeDouble('y', value.y);
    keyed.encodeNullableString('label', value.label);
  }
}
```

For nested models or lists inside a manual `KeyedDecoder` loop:

- **Single nested object**: `owner = keyed.decodeValue(const UserCodable());` (or
  `owner = const UserCodable().decode(keyed.nestedDecoder());`).
- **Nullable nested object**:
  `owner = keyed.decodeNullableValue(const UserCodable());`
- **List of nested objects**: `items = keyed.decodeList(const ItemCodable());`
- **Primitive lists**: `tags = keyed.decodeStringList();` or
  `coords = keyed.decodeFloat64List();`

### B. Custom Field Converters (`Codable<T>`)

Because `Codable<T>` is a companion interface (`T decode(Decoder)` and
`void encode(T value, Encoder)`), custom field converters implement the exact
same `Codable<T>` contract! Use this to serialize third-party types, normalize
inconsistent wire formats (for example, accepting either integer epoch
milliseconds or ISO-8601 strings for a `DateTime`), or pack custom values:

```dart
import 'package:codable/codable_json.dart';

final class FlexibleDateTimeCodec implements Codable<DateTime> {
  const FlexibleDateTimeCodec();

  @override
  DateTime decode(Decoder decoder) {
    // Fast path when streaming JSON tokens: inspect the next token type directly.
    if (decoder is JsonCodableDecoder) {
      final token = decoder.reader.peek();
      if (token == JsonTokenType.number) {
        return DateTime.fromMillisecondsSinceEpoch(decoder.reader.readInt());
      }
      return DateTime.parse(decoder.reader.readString());
    }

    // Fallback for generic SingleValueDecoder drivers:
    final raw = decoder.singleValue().readString();
    final epochMs = int.tryParse(raw);
    return epochMs != null
        ? DateTime.fromMillisecondsSinceEpoch(epochMs)
        : DateTime.parse(raw);
  }

  @override
  void encode(DateTime value, Encoder encoder) {
    encoder.singleValue().encodeString(value.toIso8601String());
  }
}
```

Attach the custom codec to any field with `@CodableKey(customDecoder: ...)`:

```dart
@Codable()
class Event {
  @CodableKey(customDecoder: FlexibleDateTimeCodec())
  final DateTime timestamp;

  const Event({required this.timestamp});
}
```

### C. Polymorphic Subtype Dispatch

To decode a sealed or abstract class hierarchy based on a discriminator field
(such as `{"type": "car", ...}` vs. `{"type": "bicycle", ...}`), implement a
companion `VehicleCodable implements Codable<Vehicle>` or provide a
`SuperDecodable<T>` descriptor. See
[`example/polymorphic_example.dart`](example/polymorphic_example.dart) for a
complete working example.
